## 验证方法与边界

云端核心使用可回滚、串行化的内存事务替身，验证并发领取、归因去重、幂等和事务一致性。它不能证明腾讯云数据库的真实事务冲突、配额、权限或索引配置正确。

页面测试模拟 `wx`、`Page` 和 `getApp`，执行实际页面事件与游戏逻辑，检查从开局、点卡、终局、领取、复制到分享的代码路径。它不是微信 WXML/WXSS 编译，也不是设备交互测试。

同步测试使用可注入的发送函数，覆盖无配置、故障重试、租约、依赖顺序和失败恢复。HTTPS 适配服务尚不存在，没有执行真实网络合同测试。

## 仍需项目方环境才能执行

- 微信开发者工具导入、WXML/WXSS 原生编译、调试基础库兼容性。
- iOS / Android 真机布局、触摸反馈、AI 运行耗时、后台恢复。
- 真实 AppID 的邀请卡片和不同用户首次来源归因。
- 微信手机号权限、隐私授权、一次性 code 换号与拒绝场景。
- 云函数部署、云数据库权限、索引和事务并发，以及定时器可用性。
- BesChannels 实际接口、联系人去重、授权同步、销售路由及故障恢复。
- 如启用企业微信客服，实际企业关联和客服会话打开。

当前成果应称为“开发交付版”，不能称为“已上线可扫码获客的小程序”。取得 AppID 等条件后，按 [开发部署与验收](开发部署与验收.md) 完成以上检查。
