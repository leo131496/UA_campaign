# 项目急救局 · 微信原生小程序开发交付

这是一套面向 B2B 活动获客的微信原生小程序代码：**直接玩资源策略挑战 → 领取实用工具包 → 自愿分享给同行 → 新访客进入 → 自愿咨询 → 同步至 SCRM**。入口不填企业信息，不使用 WebView。

当前可交付的是开发项目与方案。默认 `demo` 模式在本机演示完整流程，不采集真实手机号、不制造新增数据。尚无 AppID、云环境或 BesChannels 接口资料，**未发布微信体验版，未接通真实 SCRM**。GitHub 是源码交付入口，无法直接运行微信小程序。

## 没有 AppID 时如何交接

1. 开发人员安装并登录微信开发者工具，导入本目录；项目根目录应直接包含 `project.config.json`。
2. 暂时使用工具提供的测试号／无 AppID 本地项目方式，保留 `config.js` 的 `mode: 'demo'`。不同版本的工具可能要求先创建自己的测试项目，再复制本目录文件。
3. 从“活动”页开始：选卡、点模块，完成一局，领取资料，打开邀请卡，再用虚拟身份演示咨询。
4. 本地演示不需要前端依赖安装。分享、手机号和云数据库的真实联调必须换为自己的 AppID 和云环境。

本机没有微信开发者工具，因此上述原生导入与真机运行仍需开发团队执行；已完成的是代码检查和模拟微信接口的流程测试。

## 开发检查

Node.js 18+，在本目录运行：

```bash
npm test
npm run check
npm run check:release
```

前两项不需要安装依赖。`check:release` 在当前演示配置下应失败，提示补齐 AppID、正式模式与云环境。它不是微信审核或云环境联调的替代品。

云函数各自独立部署；微信服务端依赖锁定为 `wx-server-sdk@4.0.2`。不要将密钥放进小程序代码。SCRM 地址与令牌只配置在云函数环境变量中。

## 已有能力与待接入项

- 已实现：可玩的六回合游戏、根据局面搜索的本地 AI、断点恢复、云端重放校验、资料领取、微信分享路径、邀请漏斗、手机号授权流程、独立咨询/复盘/营销授权、撤回营销授权、SCRM 事件队列。
- 待联调：真实微信身份、手机号权限、微信原生分享卡片、云事务/权限/索引、SCRM 适配服务、企业微信客服配置。
- 未实现：扫码海报生成、多人实时对战、现金券核销、排行榜、自动加企微好友、大模型生成、BesChannels 管理端界面。它们不作为本次可用能力宣传。

AI 是实际执行的有限宽度策略搜索，能给当前棋局建议和同关参考成绩；没有调用大语言模型。分享卡带活动与邀请标记，不保证好友拿到与邀请人相同的随机局面。
