# 手机端在线交互演示

线上入口：<https://leo131496.github.io/UA_campaign/>。手机打开占满屏幕，电脑打开以手机尺寸展示。

本目录为微信原生项目提供浏览器预览，不是独立的正式 Web 产品。`build.cjs` 只将小程序前端的 38 个文件打包，`preview.js` 映射本项目实际使用的页面组件、导航和本地存储；没有打包任何云函数、令牌或真实客户资料。

- 使用原生项目的七页 WXML、WXSS、页面 JS、游戏引擎和明确的 demo 数据服务。
- 游戏、AI 提示、资料领取与复制、虚拟咨询、个人记录可以交互。
- 浏览器分享按钮提供可复制的演示链接。它不模拟微信已分享成功，也不增加拉新人数。
- 微信手机号、客服及 SCRM 调用不接入；始终强制演示模式，即使原生项目后来改成云模式。
- 只支持本项目使用到的组件和 API，不能作为通用小程序运行环境或原生兼容性证明。

原生页面修改后，在仓库根目录运行 `node phone-demo/build.cjs` 更新打包文件；`node phone-demo/build.cjs --check` 检查预览是否与原生源文件一致。

本地可在仓库根目录启动静态文件服务查看 `index.html`。原生代码、云服务与部署说明仍在 `wechat-miniprogram/`。

浏览器验证：安装 Playwright 后运行 `node tests/phone-preview.test.cjs`，默认访问本地 8771 端口，可用 `DEMO_BASE_URL` 指定其他地址。检查 320/390 像素手机布局、真实选卡通关、动态 AI、工具包、分享链接、虚拟咨询、营销撤回与刷新后记录恢复。截图默认保存到 `/tmp/ua-phone-preview`。浏览器检查不代替微信真机验收。
